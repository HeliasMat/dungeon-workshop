# The Wiki's pages: nodes, tracks, the engine's own commands, the game's words
# (workshop/src/wiki/written.rs).

== prop
> Sets properties of someone or of a node, several on one line: angle 45 scale 1.5 opacity 50%, a tint, a position…
scene: beach pikachu piplup
pikachu prop angle 20 scale 1.5
piplup: You look taller.

== node
> A node of your own: a group (nothing but a place, to attach things to), or a picture from a file; node name off removes it.
scene: beach pikachu piplup
node moon image letter.png 200 60
prop moon opacity 0.5

== attach
> Something hangs from a parent and follows it (turns and fades with it), at dx dy; inherit says what it takes.
scene: beach pikachu piplup
node raft group 200 180
pikachu attach raft 0 -8
prop raft x 300

== detach
> It no longer hangs from anything and stays where it is.
scene: beach pikachu piplup
node raft group 200 180
pikachu attach raft 0 -8
pikachu detach

== arrives
> Comes in from where the view does not go (or in smoke if there is no way), walking or running, to a point.
scene: beach pikachu piplup
piplup arrives walk - 300 180
pikachu: Hi!

== attr
> Raw flags of someone: 32 blinks, 64 transparent, 128 hidden, 8 on top (better: blink, opacity, layer).
scene: beach pikachu piplup
pikachu attr 64
piplup: You look faded.

== audience
> Those named look at whoever speaks, at each line; audience off: no one does.
scene: beach pikachu piplup eevee
audience off
pikachu: Nobody looks at me.

== backdrop
> Shows a place's backdrop in place of the scene's.
!retired

== blink
> Someone blinks on and off, until blink a off.
scene: beach pikachu piplup
pikachu blink on
wait 1s
pikachu blink off

== body
> The size of a body on screen, in pixels, for the framings to fit it (the film does it for big ones).
scene: beach pikachu piplup
pikachu body 40 40
frame pikachu piplup

== bounds
> They stay inside a rectangle (left top right bottom); bounds off frees them.
scene: beach pikachu piplup
bounds 100 100 400 250
pikachu walk to right
bounds off

== boxside
> The dialogue box at the top or at the bottom (box top in a film).
scene: beach pikachu piplup
boxside top
pikachu: Up here.

== calc
> A calculation kept under a name: + - * / div % min max.
scene: beach pikachu piplup
calc apples 3 + 2
pikachu: I have {apples} apples.

== color
> colour, another spelling: someone tinted a colour (r g b), for so long.
scene: beach pikachu piplup
color pikachu 255 120 120 10f
uncolor pikachu 10f

== uncolor
> uncolour, another spelling: someone's own colours back.
scene: beach pikachu piplup
color pikachu 120 120 255 10f
uncolor pikachu 10f

== goes
> Goes through these points, round walls and people, walking or running.
scene: beach pikachu piplup
pikachu goes walk - 300 180

== gone
> Takes someone (or something) out of the scene at once.
scene: beach pikachu piplup
gone piplup
pikachu (surprised): Where did he go?

== if
> Plays the lines up to end only if a test is true (else for the other case).
scene: beach pikachu piplup
if chance(50)
  pikachu: Lucky!
end

== keepframe
> Keeps them all in view, wherever they go; keepframe off.
scene: beach pikachu piplup
keepframe pikachu piplup
pikachu walk to right
keepframe off

== keeponly
> All the others leave the scene at once.
scene: beach pikachu piplup eevee
keeponly pikachu
pikachu: All alone.

== wall
> A wall of the place: they cannot go into it and slide along it; wall off.

== while
> Plays the lines again as long as a test is true.
scene: beach pikachu piplup
let hops = 0
while hops < 3
  pikachu jump
  hops = hops + 1
end

== zoom

== set
> Raises a flag of the game, kept once the film ends: the story tests it later (if met_piplup). set flag off lowers it again; set flag 3 gives it that value.
scene: beach pikachu piplup

set met_piplup

== turnby
> Turns someone so many eighths from where they look, at once: counter-clockwise, clockwise below 0. The game turns heads so to look around or shake no (look around, shake_head).
scene: beach pikachu piplup
pikachu turnby 2
pikachu: Hmm?
pikachu turnby -2
